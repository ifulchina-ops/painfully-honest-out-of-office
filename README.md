A brutally honest but still polite out-of-office auto-reply, written by a small deterministic program. One sentence, 189 characters: it admits the private truth — a break repeatedly cancelled out of fear of the inbox — while reassuring the sender their message is safe and promising a proper reply once the sender is human again.

## Run it

```sh
python3 main.py
```

This writes the reply to `/output/entry.txt`.
